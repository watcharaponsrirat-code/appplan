# Hongson Plan

ระบบงานแผนและงบประมาณสำหรับทดลองในเครื่อง เก็บข้อมูลด้วย SQLite และเปิดผ่านเบราว์เซอร์ที่ `http://127.0.0.1:4310` รอบล่าสุดเพิ่มแบบเขียนโครงการ 19 หัวข้อ ตาราง SOPAA ตารางประเมินผล และหน้าพิจารณาตามไฟล์โรงเรียนที่ได้รับ

## เริ่มใช้งานจาก GitHub

ติดตั้ง Node.js 24 ขึ้นไป ดาวน์โหลดหรือ clone repository แล้วเปิด Terminal ในโฟลเดอร์โปรเจกต์:

```sh
npm start
```

เปิด `http://127.0.0.1:4310` แล้วเข้าสู่ระบบด้วย `teacher` / `Demo@2569` โปรแกรมสร้างฐานข้อมูลทดลองใน `data/` ให้อัตโนมัติ กด `Ctrl+C` เพื่อหยุดเซิร์ฟเวอร์ โปรเจกต์ใช้โมดูลที่มากับ Node.js จึงไม่ต้องติดตั้ง npm dependencies เพิ่ม

ชุดซอร์สโค้ดมีรายการอ้างอิงสมมติใน `public/school-reference-data.example.json` สำหรับทดลองฟอร์ม รายการเหล่านี้ไม่ใช่มาตรฐานหรือนโยบายจริงของโรงเรียน หากมีไฟล์ `public/school-reference-data.json` ระบบจะใช้รายการจริงจากไฟล์นั้นแทน โดยไฟล์จริงและเอกสารต้นฉบับถูกยกเว้นจาก Git

Windows สามารถดับเบิลคลิก `Start-Hongson.cmd` ได้เช่นกัน ตัวเปิดแอปใช้ Node.js ที่ติดตั้งในเครื่องเมื่อไม่มี `.runtime/node.exe`

## นำโค้ดขึ้น GitHub

1. แตกไฟล์ `Hongson-Plan-source.zip`
2. สร้าง repository บน GitHub แล้วอัปโหลดไฟล์และโฟลเดอร์ภายใน ZIP รวม `.gitignore` โดยให้ `package.json` อยู่ที่รากของ repository
3. เปิดดู `README.md` ใน repository เพื่อทำตามวิธีรันด้านบน

ZIP รวมซอร์สโค้ด ชุดทดสอบ คู่มือ และข้อมูลอ้างอิงตัวอย่าง ส่วนฐานข้อมูลที่ใช้งานอยู่ ไฟล์บันทึก เอกสารโรงเรียน และโปรแกรมใน `.runtime/` เก็บไว้เฉพาะเครื่อง การเก็บโค้ดบน GitHub ยังต้องมีเครื่องที่รันเซิร์ฟเวอร์ Node.js เพื่อเปิดใช้ระบบ

สร้าง ZIP ใหม่จากโค้ดปัจจุบันด้วย PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-source.ps1
```

ไฟล์จะอยู่ใน `dist/` สคริปต์รวมเฉพาะรายการซอร์สโค้ดที่กำหนดไว้ หากเพิ่มไฟล์ชนิดใหม่ให้ตรวจรายการในสคริปต์ก่อนจัดชุดส่งมอบ

## เปิดใช้งาน

1. เปิดโฟลเดอร์โปรเจกต์ แล้วดับเบิลคลิก `Start-Hongson.cmd`
2. เมื่อเบราว์เซอร์เปิด ให้เข้าสู่ระบบด้วยชื่อผู้ใช้ `teacher` และรหัสผ่านทดลอง `Demo@2569`
3. เลือก **เขียนโครงการ** กรอกข้อมูลและรายการทรัพยากร แล้วบันทึกฉบับร่าง เปิดรายการที่บันทึกและกด **ตัวอย่างโครงการ** เพื่อพิมพ์หรือบันทึก PDF
4. ใช้ปุ่ม **ทรัพยากรไม่มียี่ห้อ** สำหรับเอกสารแนบเล่มแผน หรือ **ทรัพยากรมียี่ห้อ** สำหรับพัสดุ ส่วนฉบับที่อนุมัติแล้วเปิดจากประวัติและกด **พิมพ์ฉบับอนุมัตินี้** ได้

ตัวเปิดแอปใช้ Node.js ที่ `.runtime\node.exe` หากไม่มีไฟล์นี้ต้องมี Node.js 24 ขึ้นไปในเครื่อง การเปิดซ้ำจะใช้เซิร์ฟเวอร์เดิมเมื่อกำลังทำงานอยู่

บันทึกร่างได้แม้ยังไม่ครบ เมื่อส่งตรวจ โครงการที่สร้างด้วยแบบใหม่ต้องมีข้อมูลหลัก ขั้น SOPAA ครบ 5 ขั้น และตัวชี้วัดพร้อมวิธีประเมิน/เครื่องมืออย่างน้อย 1 รายการ แต่ละขั้น SOPAA เพิ่มกิจกรรมได้หลายรายการ

หากไม่เปิดอัตโนมัติ ให้เปิด PowerShell ในโฟลเดอร์โครงการแล้วรัน:

```powershell
node server.mjs
```

จากนั้นเปิด `http://127.0.0.1:4310` ด้วยเบราว์เซอร์ คงหน้าต่าง PowerShell ไว้ระหว่างใช้งานและกด `Ctrl+C` เพื่อหยุดเซิร์ฟเวอร์ที่เปิดด้วยคำสั่งนี้ หากเริ่มจากตัวเปิดแอปแล้วเกิดข้อผิดพลาด ดู `logs\server-error.log`

หากเซสชันหมดอายุ ระบบจะแสดงหน้าเข้าสู่ระบบแทนส่วนหัวผู้ใช้เดิม แบบฟอร์มที่ยังกรอกอยู่จะเก็บไว้ชั่วคราวในแท็บเดิม เมื่อเข้าสู่บัญชีเดิมและยังมีสิทธิ์เดิมจะกลับมากรอกต่อได้ ให้ตรวจทานและกดบันทึกอีกครั้ง ระบบไม่ส่งคำสั่งเดิมซ้ำอัตโนมัติ การรีเฟรช/ปิดแท็บ การออกจากระบบเอง หรือการเปลี่ยนบัญชีจะไม่เก็บแบบฟอร์มชั่วคราวนี้ หากบันทึกสำเร็จก่อนเซสชันหมดอายุ ระบบจะแจ้งให้เข้าสู่ระบบเพื่อดูข้อมูลล่าสุด

## แชร์ลิงก์ทดลองผ่านอินเทอร์เน็ต

ดับเบิลคลิก `Start-Hongson-Share.cmd` รอจนเปิดเบราว์เซอร์ แล้วคัดลอก **ลิงก์เต็มจาก `logs\share-url.txt`** ส่งให้ผู้ทดลอง ต้องมีส่วน `#key=...` ติดไปด้วย ลิงก์ในแถบที่อยู่จะถูกลบรหัสออกหลังเปิดสำเร็จ จึงไม่ควรคัดลอกจากแถบที่อยู่ ผู้ที่มีลิงก์เต็มเข้าถึงหน้าระบบทดลองได้ แล้วเข้าสู่ระบบด้วย `teacher` / `Demo@2569` ตามเดิม

- เครื่องนี้ต้องเปิดอยู่ ไม่เข้าโหมดพัก และต่ออินเทอร์เน็ต ระหว่างแชร์จะมีโปรแกรมทำงานเบื้องหลัง
- หยุดแชร์ด้วย `Stop-Hongson-Share.cmd` ลิงก์เดิมจะหยุดทำงาน เมื่อเริ่มแชร์รอบใหม่จะได้ลิงก์ใหม่
- โหมดแชร์ใช้ฐานข้อมูลแยกที่ `data\hongson-share.sqlite` ข้อมูลที่ผู้ทดลองบันทึกจะอยู่ร่วมกันในไฟล์นี้และยังอยู่เมื่อเริ่มแชร์ครั้งต่อไป ข้อมูลใน `data\hongson-demo.sqlite` ของการเปิดในเครื่องไม่ได้ถูกนำไปแชร์
- บัญชีและข้อมูลราคาเป็นชุดทดลอง ผู้ที่มีลิงก์สามารถทดลองทุกบทบาทตามบัญชีที่หน้าเข้าสู่ระบบแสดง จึงควรใช้เฉพาะข้อมูลทดลองและส่งลิงก์ให้ผู้ร่วมทดสอบเท่านั้น
- มีการตรวจรหัสในลิงก์ก่อนส่งหน้าจอหรือ API ของระบบ และใช้ HTTPS พร้อมคุกกี้ HttpOnly/Secure

ใช้ [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) ซึ่งเป็นลิงก์ชั่วคราวสำหรับทดลอง ไม่มีการรับประกันความต่อเนื่องของบริการ การแชร์บน Windows ต้องเตรียม `cloudflared.exe` ไว้ใน `.runtime` โดยดาวน์โหลดจาก [แหล่งทางการ](https://developers.cloudflare.com/tunnel/downloads/) โปรแกรมนี้ไม่รวมในชุดซอร์สโค้ดและไม่ได้ติดตั้งเป็น Windows service

## ข้อมูลและขอบเขต

ข้อมูลทดลองอยู่ที่ `data\hongson-demo.sqlite` และไฟล์ประกอบของ SQLite ในโฟลเดอร์เดียวกัน การปิดเบราว์เซอร์ไม่ลบข้อมูล เอกสารต้นฉบับในเครื่องผู้พัฒนาอยู่ใน `references` และไม่ได้รวมในชุดซอร์สโค้ด เช่นเดียวกับรายงานตรวจเอกสารใน `reference-review` ลิงก์ไปยังรายงานเหล่านี้จะเปิดได้เฉพาะเครื่องที่มีไฟล์

ระบบยังใช้บัญชีทดลองและข้อมูลราคาทดลอง รายการข้อ 3–4 และ 6–11 ใช้ข้อมูลสมมติในชุดซอร์สโค้ด หรือใช้รายการจริงเมื่อมี `public/school-reference-data.json` ในเครื่อง ข้อ 3 เลือกจาก dropdown และข้อ 4 เติมกลยุทธ์ที่สัมพันธ์กันอัตโนมัติ ข้อ 6–11 แสดงช่องติ๊กจัดกลุ่มตามหัวข้อหลัก ติ๊กหัวข้อหลักแล้วเห็นข้อย่อย เลือกหรือยกเลิกแล้วอัปเดตทันทีโดยไม่ต้องกดเพิ่ม ข้อความแสดงเต็มและบันทึกพร้อมโครงการ มีช่องค้นหาเลขข้อหรือภาษาไทยหนึ่งช่องต่อหัวข้อให้เปิดใช้เมื่อต้องการ ข้อมูลเดิมที่พิมพ์ไว้ยังอยู่และต้องตรวจจับคู่ก่อนส่งตรวจ ดู [ผลตรวจรายการอ้างอิง](reference-review/catalog-review.md) ได้เฉพาะเครื่องที่มีเอกสารโรงเรียน

เมนู **บันทึกข้อความ / คำขอ** สร้างคำขอทั้ง 6 ประเภทได้ทันที เชื่อมโครงการได้ทุกสถานะ หากยังไม่มีโครงการ บันทึกร่างก่อนได้แล้วเชื่อมก่อนส่งตรวจ การสร้างและส่งคำขอไม่อนุมัติโครงการหรือหักงบ พัสดุยังกันวงเงินเมื่อมีคำขออนุมัติและวงเงินโครงการเพียงพอ

ยังไม่เชื่อม Google Sheets หรือบริการแจ้งเตือนโทรศัพท์ และยังไม่เผยแพร่เว็บไซต์ถาวร สามารถเปิดลิงก์ทดลองชั่วคราวด้วยตัวเริ่มแชร์ด้านบน แบบเอกสารชนิดอื่นยังต้องเทียบกับต้นฉบับต่อ ส่วนหน้าจอและการตัดหน้าพิมพ์ของแบบโครงการยังต้องตรวจผ่านเบราว์เซอร์จริง

ดูสถานะล่าสุดใน [แผนดำเนินงาน](IMPLEMENTATION_PLAN.md) และที่มาของช่องข้อมูลใน [ผลตรวจแบบเขียนโครงการ](reference-review/project-form-review.md)

## ตรวจชุดทดสอบ

รันจากโฟลเดอร์โครงการด้วย Node.js 24 ขึ้นไป:

```powershell
npm test
```

ชุดทดสอบครอบคลุม dropdown และ checkbox การค้นหา/เปิดข้อย่อย/ยกเลิก การป้องกันรายการซ้ำ ข้อความพิมพ์จากสำเนาที่บันทึกไว้ การบันทึกและเปิดกลับหลังเริ่มเซิร์ฟเวอร์ใหม่ คำขอทุกประเภท สิทธิ์ การคำนวณงบ และประตูเข้าลิงก์แชร์ ชุดซอร์สโค้ดทดสอบด้วยรายการอ้างอิงตัวอย่าง ส่วนการตรวจความครบถ้วนของเอกสารโรงเรียนจะข้ามเมื่อไม่มีไฟล์รายการจริงในเครื่อง

การตรวจอัตโนมัตินี้ยังไม่ครอบคลุมภาพหน้าจอและการตัดหน้าจากเบราว์เซอร์จริง สคริปต์เสริม `scripts/extract_references.py` ใช้สำหรับตรวจเอกสารต้นฉบับในเครื่องผู้พัฒนา ต้องติดตั้ง Python พร้อม `pypdf`, `openpyxl` และ `Pillow` แยกต่างหาก การเปิดแอปและรันชุดทดสอบ Node.js ไม่ต้องใช้ Python
